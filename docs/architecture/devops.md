# DevOps learning plan

The deployment path is incremental:

1. Reliable local development with Docker Compose.
2. Reproducible frontend and backend container images.
3. Automated build and test pipelines.
4. Kubernetes Deployments and Services for stateless applications.
5. Ingress, TLS, configuration, secrets, probes, and resource limits.
6. Metrics, logs, traces, alerts, and safe rollbacks.

PostgreSQL, Kafka, and TURN require persistence and operational care. Do not copy development deployments directly into production.
